# FinanceForecaster: Algorithmic Market & Crypto Trend Engine

## Project Overview
This project analyzes two years of historical stock market data for Apple (AAPL), Microsoft (MSFT), and Tesla (TSLA) using Python. It explores stock price trends, daily returns, moving averages, and volatility.

## Objectives
- Download historical stock data using yfinance.
- Explore and analyze stock datasets using Pandas.
- Visualize stock prices using Matplotlib.
- Calculate daily returns.
- Analyze 20-day and 50-day moving averages.
- Compare stock volatility.

## Technologies Used
- Python
- Google Colab
- yfinance
- Pandas
- Matplotlib

## Stocks Analyzed
- Apple (AAPL)
- Microsoft (MSFT)
- Tesla (TSLA)

## Key Findings
Tesla showed the highest daily volatility among the three stocks analyzed, followed by Microsoft and Apple.
